## English introduction

I built PlainCraft for people who like GPT's coding ability but want a more natural conversation. It helps carry context forward, answer the actual need, and explain decisions without canned framing. It also asks for careful assumptions, counterexamples and meaningful checks, so “natural” doesn't mean shallow.

Try it by copying a prompt into ChatGPT, or installing the Codex skill and typing `$plaincraft`. It follows your language; there is no proxy, API key or hosted service.

The first six-scenario trial was a near tie with an already strong baseline; both sets of code passed the same 28 checks. Raw prompts and answers are included. I'd especially value examples where it loses facts, misunderstands a follow-up, or makes code worse, alongside style feedback.
